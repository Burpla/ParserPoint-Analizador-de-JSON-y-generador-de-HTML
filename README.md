# ParserPoint-Analizador-de-JSON-y-generador-de-HTML
Aplicación de escritorio en Python con PLY y Tkinter que analiza documentos JSON de equipos, integrantes y proyectos, detecta errores léxicos y sintácticos y genera HTML para visualizar y exportar. Proyecto académico de Sintaxis y Semántica de los Lenguajes (2025).
